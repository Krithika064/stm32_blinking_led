Automatic Sensor-Based LED Control System Using STM32
Aim

To interface a digital sensor with an STM32 microcontroller and automatically control an LED according to the sensor output.

Components Required
S. No.	Component	Quantity
1	STM32 development board	1
2	Digital sensor or push button	1
3	LED	1
4	220–330 Ω resistor	1
5	Breadboard	1
6	Jumper wires	As required
7	USB cable	1
Pin Configuration
Component	STM32 pin	Pin mode	Purpose
Sensor output	PA0	GPIO input	Reads the sensor condition
LED	PA5	GPIO output	Controls the LED
Sensor VCC	3.3 V	Power	Powers the sensor
Sensor GND	GND	Ground	Provides common ground
Circuit Connections
Connect the VCC pin of the sensor to the STM32 3.3 V pin.
Connect the GND pin of the sensor to the STM32 GND pin.
Connect the OUT pin of the sensor to PA0.
Connect PA5 to the LED anode through a 220–330 Ω resistor.
Connect the LED cathode to GND.
If the development board has an onboard LED connected to PA5, an external LED is not required.
Working Principle

The sensor is connected to PA0, which is configured as a digital input. The LED is connected to PA5, which is configured as a digital output.

The STM32 continuously reads the sensor output.

When the sensor output is HIGH, the STM32 makes PA5 HIGH and the LED turns ON.
When the sensor output is LOW, the STM32 makes PA5 LOW and the LED turns OFF.
The sensor state is checked every 100 milliseconds.
Algorithm
Start the system.
Initialize the STM32 microcontroller.
Configure PA0 as a GPIO input.
Configure PA5 as a GPIO output.
Read the sensor state from PA0.
Check whether the sensor output is HIGH.
If the sensor output is HIGH, switch ON the LED.
Otherwise, switch OFF the LED.
Wait for 100 milliseconds.
Repeat the process continuously.
GPIO Configuration
PA0 — Sensor Input

PA0 is configured as a GPIO input without an internal pull-up or pull-down resistor. It receives the digital signal generated by the sensor.

PA5 — LED Output

PA5 is configured as a push-pull GPIO output. It controls the LED according to the sensor input.

Expected Output
Sensor input at PA0	Output at PA5	LED condition
LOW	LOW	OFF
HIGH	HIGH	ON

Precautions
Use a sensor with a 3.3 V-compatible output.
Do not apply 5 V directly to an STM32 GPIO pin.
Connect the sensor ground and STM32 ground together.
Use a current-limiting resistor with an external LED.
Verify the sensor pin configuration before connecting it.
Use an appropriate pull-up or pull-down resistor if the input is unstable.
Check whether the sensor uses active-HIGH or active-LOW logic.
Result

The digital sensor was successfully interfaced with the STM32 microcontroller. The LED connected to PA5 turned ON when the sensor input at PA0 was HIGH and turned OFF when the sensor input was LOW.
